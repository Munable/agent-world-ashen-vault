# M1 验证记录

这是11fe121时代的83项历史基线。新增G1的测试结果见 [G1_VALIDATION.md](G1_VALIDATION.md)，不把新增成绩倒填到旧版本。

版本：0.1.0a1。规则来源：SRD 5.2.1，见 `srd-source.json`。这是首个可运行规则里程碑，不是三个职业与完整地城的最终验收。

## 验证种类

`tests/test_rules.py`：纯机械函数，固定骰点作为测试替身。包括攻击与普通检定的 1/20 区别、优势/劣势、重击骰子、抗性顺序、临时 HP、击昏、恢复和死亡豁免基础函数。

`tests/test_engine.py`：封闭近战场景，固定合法初始状态与测试骰点。包括先攻同值裁定、存盘键顺序一致性、动作预算、拆分移动、地形、俯卧/起身、触及范围、反应窗口、拒绝非法/过期操作和终局。

`tests/test_http.py`：实际 ASGI HTTP 路由与临时 SQLite。覆盖两个身份独立加入、私有鉴权、只读身份不能控制、禁止客户端传入骰点/伤害、并发相同操作只结算一次、不同参数重用操作 ID 被拒绝、重建运行时后反应窗口仍可处理。

`tests/test_mcp.py`：真正的 Streamable HTTP MCP 客户端与另一独立 HTTP 客户端。验证 discovery、加入、服务器先攻、原回执重放、读取同一场景；停止并重启子服务后原身份和当前回合保持不变。

`tests/test_provision.py`：本地私密身份文件能验证原角色，不打印令牌，拒绝覆盖现有文件且不额外创建角色。

`tools/check_browser.py`：真实 Playwright 浏览器读取公开场景，独立 HTTP 客户端进行行动。验证正常移动、离开触及之前暂停、实际子进程重启后窗口保持、回合外反应、放弃不花费反应、重复反应不重复生效、页面不携带令牌/Cookie/Authorization、不持久保存凭据、390px 视口无横向溢出和页面错误为零。

## 结果记录

本地单元/集成测试 **83/83 通过**，真实浏览器验收通过、页面错误为零；0.1.0a1 wheel 构建成功。

最终本地结果与对应的非敏感计数写入 `validation.json`。测试和安装包构建由 GitHub Actions 在已提交版本上复跑；CI 的最终状态以该提交的 Actions 记录为准，不用这份文字替代远端状态。

没有请求 FreeAPI，没有用网页截图冒充完整游戏；也没有把固定脚本当成两个 LLM 自主协作。没有运行负载测试，没有宣称完整安全审计、全 SRD 覆盖或所有消费级聊天客户端兼容。

## 已发现并修正的细节

初始规则测试和 HTTP 测试发现 JSON 存盘会规范化对象键顺序。先攻骰点分配现在显式按 seat 排序，避免内存初始状态与从数据库读回的状态把同一组测试骰分配给不同实体。已有 JSON 往返回归。

机会攻击不是“先移动后挨打”。窗口保存剩余路径，反应在离开之前结算，若移动者死亡/失能，路径中止而不是穿过敌人后再倒下。Decline 保留反应，Reaction 在本人下一回合开始恢复，而非统一在新一轮恢复。

未完成的内容全部留在 ROADMAP/RULES_SCOPE；不为了通过示例而修内核专用 API、不引入世界专属 provider fallback。
