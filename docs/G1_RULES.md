# G1 当前规则与内容边界

版本：0.2.0a1。规则基线固定 SRD 5.2.1；完整来源与 SHA-256 在 `srd-source.json`。这里描述已经开放的有限菜单，不是整个 Fighter、Halfling 或完整 SRD 的兼容认证。

## 构筑：固定起点与有限升级选择

一个 Halfling Fighter 从 1 级到 2 级。标准数组分配为 Str15/Dex13/Con14/Int10/Wis12/Cha8；按 SRD 第192–193页的自定义背景规则选择 Str/Dex/Con，分配 Str+2、Con+1，最终17/13/15/10/12/8。

背景“守路人”是作者内容，不冒充 SRD 的固定 Soldier 背景。背景技能 Athletics、Perception；Skilled 专长选择 Medicine、Intimidation、Stealth；职业技能 Survival、Insight；工具熟练 Carpenters' Tools。语言选择为 Common、Dwarvish、Elvish。数据中记录实际来源与数值，不用裸体 NPC 改名字冒充职业角色。

初始 Defense 风格、Chain Mail、Shield、Flail、Morningstar、Mace 和 Dungeoneer's Pack。职业 155 GP 装备选项支出127；背景50 GP支出10，余68 GP。委托者额外提供一瓶药水，明确是作者任务物品，不伪装成 SRD 免费初始装备。

三种已掌握的近战武器都使用 Sap，因此本切片可以完整结算这三种武器的相关近战效果。初始 AC19、HP12；攻击加值+5。升级时固定生命值增长为6+Con2，上限变为20，不额外回满当前 HP。可以继续 Defense 或依职业升级允许的风格替换规则选择 Dueling，形成 AC19/伤害+3 与 AC18/伤害+5 的实际取舍。

## 已接入玩法的规则

| 规则 | 当前实现 | SRD 来源纸面页 |
|---|---|---|
| 回合/普通动作/反应/移动 | 普通操作带 turn_id，附赠动作单独记账，机会攻击在离开触及前发生 | 8–18 |
| 攻击、重击、优势/劣势 | 服务器掷骰；对立来源抵消；重击翻倍骰子不翻倍固定加值 | 7–8、15–17 |
| Halfling Lucky | D20实际选择结果为1时重掷一枚；可通过 use_luck 放弃某次攻击/检定，不修改永久种族特性 | 86 |
| Halfling Nimbleness | 可以穿过较大敌人的格子，仍按敌人占据格的困难地形收费且不能自愿停在占用格 | 14、86 |
| Sap | 命中后的目标下一次攻击劣势，使用后清除，或在来源者下回合开始清除 | 90–91 |
| Second Wind | 附赠动作，1d10+职业等级；初始2次；短休恢复1次、长休全部恢复 | 47–48 |

| 治疗药水 | 自己饮用花附赠动作，2d4+2；物品真实扣除；营地50 GP购买，作者限定库存2瓶 | 95、98、236 |
| 短休 | 安全营地1小时；不自动回血；可逐枚花生命骰，根据前一枚结果决定是否继续 | 187 |

回合预算是已实现战斗的规则时钟；旅行/休息推进虚构秒数；浏览器用单调时钟安排动画。网络等待不会恢复资源或让角色自动放弃反应。虚构时间正常流逝后，不把短暂战斗效果永久留在角色身上。

## 作者内容、奖励与风险

营地、门厅、岔路、补给间、守卫前厅、祭坛是六个可往返区域。门厅目标75 XP，通行目标75 XP，火种交还150 XP，总计300 XP。战斗通行的75包含25点Guard经验和50点作者目标经验；付费/交涉通行的75是作者目标奖励，不冒充怪物死亡经验。多种解决方式共享同一持久奖励来源，只领一次。

可先花50金币补充药水，但初始68金币因此只剩18，不能再支付20金币通行；需要交涉或战斗。支出不是界面上的假扣款。补给箱有独立一次性状态，失败不能反复用新操作ID重掷；获得新Tactical Mind后，只能对当时的新失败检定作决定，不能追溯更早结果。这是此容器的作者裁定，不是所有SRD能力检定都只能一次。

Guard采用SRD第296页的近战数字。后续守印者是原创近战配置（AC16/HP18/攻击+4/1d6+2），不伪造官方怪物CR。敌人目标是制止和击昏入侵者，低血量时会选择撤退；实际仍按动作预算、路径与机会攻击规则执行。对玩家的机会攻击窗口保持等待，绝不由NPC脚本代替玩家决定。

敌人撤退、死亡或被击昏均可结束作者定义的遭遇。被击昏的玩家保留1 HP及原角色/物品，但该次远征记为被俘失败。回营主动退出另记retired，完成火种和考验才是completed，不混为一种“成功”。

## 明确未完成的规则范围

没有Rogue/Wizard、3级子职业、远程武器、完整Hide/Search/Help/Ready等通用动作、自由文本DM、所有状态与战后救助/死亡恢复、多人合作与共用世界时间。Halfling Brave/Naturally Stealthy尚无对应恐惧或躲藏场景；不能因选择了该物种就声称这些玩法已实现。

只开放当前三种近战武器和两种风格选择；没有完整的长休更换Weapon Mastery菜单，也不开放战斗中任意装备穿脱或物品使用。当前背景工具/其他技能可见于构筑记录，但并非所有技能都已有场景。

营地是作者明确保证安全的休息地点，本版本没有在休息中插入袭击、饥渴或中断后的续睡流程；不宣称完整实现所有休息中断条件。反复休息会真实推进世界内时间，但目前没有全章倒计时追兵，因此这仍是宽松的入门切片。

完整G1设计要求的规则选择闭包仍需继续补齐。正确的结论是“有限菜单可运行且核心链路已验收”，不是“一个职业/整个游戏全部完成”。
