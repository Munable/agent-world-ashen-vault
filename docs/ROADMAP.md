# 后续范围与维护顺序

更新：2026-09-26。0.3.0a1 / G2 Phase A 已合入；本文件不再重复 M1/G1/G2 的功能目录，也不把 G3 完整游戏作为默认下一阶段。

## 本轮维护

保持现有回归基线可运行。运行代码与文档不符时先记录精确偏差；通用缺陷在 Runtime 修，领域规则缺陷在本世界修。不要通过追加内容掩盖合同或测试缺口。

需要新增实验时先写明 Runtime 假设和失败条件，再判断能否在已有最小场景中验证。优先关注结构化交互、断线接续、未决状态与缓存／保留的关系。具体底层待设计项仅在 Runtime 的 [OPEN_DESIGN](https://github.com/Munable/agent-world/blob/main/docs/OPEN_DESIGN.md)维护。

## 非默认工作

完整多人探索、死亡救助、三级后冒险、更多法术和素材是可能的世界产品工作，不是 Runtime 成立的必要条件。现有三级处理器的测试夹具不等于三级冒险已经可玩，不能据此宣称完整职业体验。

## 验证与费用

精确证据见 [G2_VALIDATION](G2_VALIDATION.md)。旧源码的绿灯不能证明新改动，脚本策略不能代替真实模型，短链循环不能证明长期稳定运行。

日常修改先在本地或可控机器验证，集中提交。文档仅做内容、链接和差异检查；不为每次修改自动消耗 GitHub Actions。不要重跑已经通过且与改动无关的全套矩阵。
